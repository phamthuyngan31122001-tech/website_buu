🌐 BƯỚC 2 - Đưa lên Internet với LINK CỐ ĐỊNH VĨNH VIỄN (khuyến nghị):
────────────────────────────────────────────────────────────────
Dùng ngrok + static domain miễn phí -> URL KHÔNG đổi sau mỗi lần chạy.

Chuẩn bị 1 lần:
  1) Đăng ký: https://dashboard.ngrok.com/signup
  2) Tải ngrok: https://ngrok.com/download (đặt ngrok.exe vào PATH)
  3) ngrok config add-authtoken <TOKEN>
     (lấy ở https://dashboard.ngrok.com/get-started/your-authtoken)
  4) Tạo static domain miễn phí (1 cái/tài khoản):
     https://dashboard.ngrok.com/cloud-edge/domains -> "Create Domain"

Chạy (Terminal 2):
  powershell -ExecutionPolicy Bypass -File scripts\tunnel-ngrok.ps1 -Domain <domain-cua-ban>

📍 URL công khai CỐ ĐỊNH: https://<domain-cua-ban>   (vd https://quan-khu-5.ngrok-free.app)
✓ URL này KHÔNG đổi dù tunnel rớt và tự kết nối lại -> ổn định lâu dài.

      1. Dừng tất cả process:

      2. Chờ 2 giây
      3. Chạy lại server
   → Hoặc tìm process khác dùng port:
      netstat -ano | Select-String ":18088"
      taskkill /PID [PID] /F

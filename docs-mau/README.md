# Tài liệu mẫu

`danh-sach-mau.xlsx` là file Excel danh sách quân số mẫu, gồm các cột:

| STT | Họ và tên | Sinh ngày | Trình độ | Cấp bậc | Mức độ hoàn thành nhiệm vụ |
|-----|-----------|-----------|----------|---------|----------------------------|

Nội dung của file này được nạp sẵn vào tài liệu của các đơn vị **c1, c2, c3**
khi khởi tạo dữ liệu (xem `ensure_demo_documents` trong `src/web.rs`).
